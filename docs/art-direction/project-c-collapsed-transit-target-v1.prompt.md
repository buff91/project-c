# Collapsed Transit target v1 — ImageGen prompt

- Tool: built-in ImageGen
- Use: mood/material reference only. Runtime sprites are redrawn at final pixel
  resolution by `Tools/ArtPipeline/generate_postapoc_vertical_slice.py`.

```text
Use case: stylized-concept
Asset type: Project-C game art direction target board for a runtime isometric dungeon room
Primary request: Create one polished isometric pixel-art cutaway diorama of the first dungeon, “Collapsed Transit,” a post-apocalyptic anomalous underground transfer station. It should establish the exact visual language for a small playable room.
Scene/backdrop: cold near-black blue void around a compact 2:1 dimetric room; cracked concrete platform tiles; broken transit wall panels and exposed rebar; a heavy blast door; one short concrete stair; a collapsed floor opening; rust and sparse dead weeds; readable walkable grid.
Subject: include a lone scrap-armored expedition scout, one hooded scavenger with a metal weapon, one squat obsolete security drone, and a low leaking contamination ooze, all small and clearly separated; add a fuel drum and utilitarian locker.
Style/medium: clean chunky isometric pixel art, crisp hard pixel clusters, limited palette, game-production concept sheet quality, no antialiasing look, no painterly blur.
Composition/framing: wide 16:9-ish three-quarter isometric cutaway, one complete room readable at a glance, floor and rear walls visible, generous dark border; gameplay silhouettes more important than detail.
Lighting/mood: cold blue-black ambient darkness with small amber emergency-lamp pools; a single restrained teal anomaly signal near the sealed exit; tense abandoned infrastructure, not glossy sci-fi.
Color palette: charcoal, blue-black, desaturated concrete gray/taupe, rusty orange-brown; saturated color only amber lamps and one teal anomaly accent.
Materials/textures: chipped concrete, oxidized steel, hazard stripes used sparingly, broken ceramic platform tiles, cable conduits, soot and leaks.
Constraints: preserve strong floor/wall value separation; amber means physical light/danger and teal means anomaly; actors must remain readable against the floor; no fantasy stone arches, no medieval torches, no magic runes, no lush vegetation.
Avoid: text, labels, logos, UI, watermark, photorealism, smooth 3D rendering, neon cyberpunk overload, excessive clutter, bloom that obscures pixels.
```
