Use case: stylized-concept
Asset type: Project-C game art direction target board for a runtime isometric dungeon room
Primary request: Create one polished isometric pixel-art cutaway diorama of a ruined underground service deck inside an abandoned arcade complex. It should establish the exact material language for a small playable room.

Materials/textures: chipped concrete, oxidized steel, hazard stripes used sparingly, broken ceramic platform tiles, cable conduits, soot and leaks.
Constraints: preserve strong floor/wall value separation; amber means physical light/danger and teal means access/cooling; actors must remain readable against the floor; no fantasy stone arches, no medieval torches, no magic runes, no lush vegetation.
