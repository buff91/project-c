# AI → Aseprite 마감 워크플로 (솔로 제작 실전)

> 전제: **AI 이미지 생성은 컨셉·무드용으로만 유효**하다. PPU64 그리드, 발 피벗 고정,
> 태그별 프레임 정합을 AI가 못 맞추므로 **런타임 에셋은 Aseprite에서 손마감**해야 한다.
> 이 문서는 "AI로 뽑은 그림"을 우리 파이프라인이 받는 규격까지 끌고 오는 절차다.

## 0단계 — 규격·팔레트 고정 (제작 전 1회)

- **규격**: `docs/art-direction/asset-spec-sheet.md`의 캔버스·피벗·태그. 슬롯 하나 잡을 때마다 참조.
- **팔레트**: 아래 고정색을 Aseprite `.gpl`/팔레트로 저장해 **모든 스프라이트가 같은 인덱스**를 쓴다.
  (팔레트 규율이 서로 다른 에셋을 "한 스타일"로 묶는 가장 강한 힘.)

## 1단계 — 컨셉/무드 (AI, 씬 단위)

- AI(Midjourney/SD 등)로 **개별 스프라이트가 아니라 씬/보드**를 생성해 실루엣·색·조명만 참고.
  (지금 `project-c-artstyle-concept-v1.png`, `warm-diorama-hub-target-v1.png`가 그 역할.)
- 프롬프트 키: `isometric pixel art, warm dark fantasy dungeon, torch-lit stone,
  teal portal, limited palette, 2:1 dimetric, high contrast lighting`.
- ⚠️ AI 출력은 **레퍼런스일 뿐** — 그대로 임포트하지 않는다.

## 2단계 — 캔버스 세팅 (Aseprite)

- 슬롯 규격의 **정확한 W×H**로 새 문서. (예: 액터 48×64, 아이템 32×32, 바닥 64×32)
- 팔레트를 0단계 `.gpl`로 로드. **Indexed 모드** 권장(팔레트 이탈 차단).
- 카테고리별 **템플릿 파일** 하나씩 만들어 두면 반복이 빨라진다:
  가이드(발 기준선·타일 다이아 외곽) + 팔레트 + 빈 태그(idle/walk/attack/hit/fall/death) 프리셋.

## 3단계 — AI 참고 → 도트로 옮기기

두 경로 중 택1:

**(a) 손그림(권장·기본)**: AI 컨셉을 배경 레이어에 낮은 알파로 깔고 위에 도트로 새로 그린다.
실루엣만 빌리고 픽셀은 직접. 그리드·팔레트가 처음부터 정확.

**(b) AI 다운스케일 마감**: AI를 고해상도로 뽑아 → 캔버스 크기로 축소 → 팔레트로 **posterize/snap** →
손으로 정리. 반드시 잡을 것:
- **안티에일리어싱 제거**(픽셀 경계 흐림) → 단색 경계로
- **오프그리드 픽셀 정렬** (반 픽셀 어긋남 제거)
- **밴딩/노이즈 정리**, 색 수를 팔레트로 강제 축소

## 4단계 — 애니메이션 (해당 슬롯만)

- 태그: `idle`·`walk`·`attack`·`hit`·`fall`·`death` (필요한 것만, 시트 참조).
- **발 위치를 전 프레임 고정**: 온니언스킨 켜고 기준선 가이드에 발끝 맞춤. (피벗이 (0.5, 0.04)라 발이 흔들리면 미끄러져 보인다.)
- 반복 안 하는 태그(attack/hit/fall/death)는 **Repeat=1**.
- **Layer UUID 켜기**(레이어명 바꿔도 Unity 참조 유지).
- 소품 애니: `prop-campfire`/`prop-portal`/`env-wall-torch-*`는 `idle` 루프.

## 5단계 — 저장 (파이프라인 진입)

- **정식 파일명**으로 `Assets/_Project/Art/Source/Aseprite/<파일명>.aseprite` 저장.
- 같은 이름을 다른 폴더에 중복 저장 금지(파이프라인이 중복 경고).
- 원본이 아직 없는 슬롯은 건드리지 말 것 — 기존 PNG 폴백이 자동 유지된다.

## 6단계 — Unity 자동 처리 확인

- 복귀 시 자동: Point / PPU64 / MipOff / 무압축 / Canvas 피벗 / (다중 프레임 시) AnimationClip.
- 첫 프레임이 `ProjectCEnvironmentCatalog` 대응 슬롯에 자동 연결.
- `Project-C > Art > Aseprite > Validate Sources` 실행 → 파일명·규격·프레임 경고 0 확인.

## 7단계 — 실기 검증

- **Unity MCP**로 실제 Play 캡처: 모바일 세로 + PC 가로 각각.
  FOV 3상태(Unknown/Explored/Visible)에서 톤이 유지되는지, 발/피벗이 타일에 정확히 앉는지 확인.
- 회귀: EditMode `ProjectC.Tests.EditMode` **673** / PlayMode `ProjectC.Tests.PlayMode` **1**.

## 배치 제작 팁 (솔로 효율)

1. **캔버스 크기별로 묶어서** 제작(아이템 12종 → 32×32 배치, 벽 4종 → 32×56 배치).
2. 카테고리 **템플릿 재사용**(팔레트·가이드·태그 프리셋 포함).
3. **대표 1장 먼저 완주**(floor→wall→player→torch 순)해 파이프라인 전 구간을 뚫고 톤 확정한 뒤 확산.
4. 색은 **토큰에서만** — 새 색은 씬 실측 후 토큰화. 화면 USS/스프라이트에 임의색 금지.
