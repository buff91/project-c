## 1. 가독성 규칙 (이번에 확정)

"헷갈린다"의 원인은 스타일이 아니라 **역할 신호의 부재**였다. 아래 규칙은 모든 신규
아트·절차 생성에 적용한다.

### 1-a. 진영 색 언어 (색은 역할이다)

| 진영 | 신호색 | 사용법 |
|------|--------|--------|
| 적 | **경고 네온 `#F0492A`** (`--pc-warning`) | 눈/바이저/램프 등 **포인트 1곳**. HP 적색(`#D8452A`)과 역할 분리 유지 |
| 영웅·동료 | **틸** (`--pc-teal` 계열) | 포인트 1곳(스카프/밴드/랜턴). 플레이어 발판 마커와 같은 계열 |
| 중립 NPC | **앰버** (`--pc-amber` 계열) | 포인트 1곳(랜턴/완장). 광원색과 동일 계열이라 "안전"으로 읽힌다 |

- 몸통 베이스색은 진영 간 **명도 2단 이상** 분리한다(동료 가죽색 ≈ 고블린 몸통 사고 재발 방지).
- 신호색을 넓은 면적에 쓰지 않는다 — 포인트가 넓어지면 광원·상태이상 판독을 방해한다.

### 1-b. 실루엣 계약 (몬스터별 고유 외곽 1요소)

| 아키타입 | 고유 실루엣 | 비고 |
|----------|------------|------|
| Goblin(약탈자) | 웅크린 어깨 + 배낭 | 근접 기준몹 |
| Skeleton(경비 드론) | 각진 몸통 + 안테나 | 탱커, 직선 실루엣 |
| Slime(오염 슬러지) | 낮고 넓은 덩어리 | 저채도 유지 — 틸 신호색과 겹치지 말 것 |
| Slinger(투석 약탈자) | **치켜든 팔 + 투척끈** | 원거리임이 실루엣으로 읽혀야 대응이 성립 |
| GraveWarden(감시자) | **일반 몹의 ~1.3배 덩치 + 센서 마스트 + 네온 외눈** | 보스 조우 즉시 인지 |

- 코드 방어선: `IsoVisualCatalog.MonsterFor`는 미등록/빈 슬롯에서 goblin이 아니라 **null**을
  반환한다(테스트 고정) — 전용 절차 폴백이 살아나 몬스터가 같은 그림으로 뭉개지지 않는다.

### 1-c. 지형 가독성 (기존 규칙 재확인 + 밴드 바닥)

- floor↔wall 명도 분리 유지. 석재 기본색은 깊이와 무관(테스트 고정) —
  깊이 변주는 **밴드 스프라이트 슬롯**(mid/deep/boss)으로만 한다: 오염·마모·장비 밀도로 구분.
- Hole=틸, 안전 계단=주황(앰버) 신호 유지. hazard(흑황)는 소량 마킹만.
- 던전 바닥에 따뜻한 광원색을 굽지 않는다 — FOV·기름·물·화상·빙결 판독 우선.

## 2. 128-레짐 (2026-07 상향 완료)

- 바닥 타일 **128×64px / PPU 128** (구 64×32/PPU 64의 정확히 ×2). 월드 유닛·정렬·정규화
  피벗 불변 — `IsoGrid`는 월드 유닛 기반이라 코드 지오메트리는 손대지 않았다.
- 캔버스 전표는 `asset-spec-sheet.md`(개정판) 참조. 액터 96×128, 아이템 64×64.
- `ui-*`는 64-레짐 유지(UI Toolkit이 픽셀 크기로 소비).
- 절차 생성 코드는 64-레짐 그대로 둔다 — 스프라이트별 PPU로 공존하며,
  카탈로그 경유 경로는 톤매핑·단차가 배율 일반화돼 있다(`GetMappedTileSprite` scale).
- 피벗 SSOT는 `ProjectCArtPivots.cs` 한 곳 (Aseprite 파이프라인·PNG 임포터 공유).

## 3. 생성 배치 (ComfyUI — 사용자 실행 순서)

공통: `comfyui-to-aseprite-pipeline.md`의 그래프에 **IPAdapter 스타일 소스 = §0 레퍼런스**,
ControlNet은 기존 게임 캡처/기존 스프라이트의 라인아트. 소스시트는 기존 규격
(3×2 셀 512px 또는 627px 셀, `#ff00ff` 배경)을 유지하면 마감 스크립트가 그대로 먹는다.
산출 시트를 `docs/art-direction/`의 기존 `*-source-v2.png` 이름 관례(`…-v3.png`)로 넣고
커밋하면, 다음 세션에서 `Tools/ArtPipeline/process_postapoc_*` 재실행으로 마감한다.

### 배치 1 — 던전 환경 (맵 가독성 최우선 · v0.3.3에서 어휘를 아케이드 타워로 개정)
1. **깊이 밴드 바닥 6종**: mid/deep/boss × 기본/raised — B2~B1(주차장 유도선·침수 얼룩·곰팡이),
   1F~5F(상가 타일·네온 반사 얼룩·낙서·전단지), 6F~옥상(오피스 카펫 잔해·붕괴 노출 철근·케이블)
   순으로 오염 어휘 변화.
   파일명 계약·피벗은 코드에 등록 완료 — `env-floor-mid`(-raised)/`-deep`(-raised)/`-boss`(-raised)
   정식 파일명으로 저장만 하면 자동 연결된다 (스펙 시트 §1).
2. 기존 15장 재생성(선택): 현행 v2 소스 재사용분의 품질이 레퍼런스와 어긋나는 슬롯만.
3. `env-hole` / `env-weak-floor` / `env-ladder` — 규격 결정 포함(스펙 시트 ⚠️ 항목).

### 배치 2 — 액터 (실루엣 계약 반영)

> **2026-07-29 개정 / 2026-07-30 v2 재개정**: 액터 화풍은
> `project-c-actor-appeal-restyle-v1.md`(v2)가 SSOT다 — **2.5~3등신 스트리트웨어·컬러 헤어**,
> 아군 얼굴 노출/적 익명. 아래 항목의 실루엣·진영색 규칙은 유지하되 비율·복장·얼굴은 그 계약을 따른다.
1. **`actor-slinger`** / **`actor-grave-warden`** — §1-b 실루엣 필수. 현재 절차 아트가

2. 기존 8종 96×128 재생성 — idle 베이스 포즈까지만 AI, 애니 프레임은 Aseprite 손작업.
3. 진영 색 언어(§1-a) 적용: 적 4종 네온 포인트, 영웅 3종 틸 포인트, merchant 앰버.

### 배치 3 — 아케이드 소품 + 낙하/구멍 (ROADMAP §아케이드 소품과 합류 · v0.3.3 개정)
자판기·네온 간판·홀로 패널·셔터 내린 점포·엘리베이터 통로 마감재 + `env-hole` 깊이 표현.
(구 병원 소품 목록 — 들것·커튼 레일·수술등·약품 캐비닛 — 은 집행 전 폐기.)
낙하 시스템은 "남은 것은 아트뿐" 상태 — 이 배치가 끝나면 낙하 연출이 완성된다.

### 배치 5 — 전투 공간 정체성 + 무드 백드롭 (v0.3.3 신설)

배경은 세 층위로 나뉘고, 각 층위의 소유자가 다르다:

1. **게임플레이 타일 환경** — 배치 1이 소유(층 밴드 바닥·벽). 판독 규칙 §1-c 우선.
2. **전투 공간 정체성** — "CP2077의 전투 장소가 턴제 아이소가 된" 느낌. 층 밴드마다
   **장소성 있는 아레나 어휘**를 정한다: B2~B1 주차장(기둥·폐차·웅덩이 엄폐) →
   1F~5F 아케이드 홀(자판기·셔터 점포·에스컬레이터 잔해) → 6F~ 오피스/주거(파티션·
   케이블 트레이) → 옥상. 어휘는 **타일+소품 조합**으로 구현하고 별도 씬을 만들지 않는다 —
   방향 타깃: `comfyui/output/backdrop-targets-v1/combat-*` → 승인본을
   `project-c-combat-space-target-v1.png`로 승격.
3. **무드 백드롭** — 비(非)타일 분위기 배경: 메인 메뉴(네온 시티 스카이라인 v2 —
   구 `main-menu-backdrop-source-v1` 교체), 허브 원경, 결과 화면, 층 진입 인터스티셜.
   `ui-*` 960×540/PPU 64 규격, 신호색 판독 규칙의 적용을 받지 않는 유일한 층위
   (게임플레이 화면에 겹치지 않을 때 한정).

### 배치 4 — 아이템 리스킨 (reskin-table 준수)
물약→구급팩, 두루마리→신호탄, 유물→기록장치 등 12종을 64×64로.
