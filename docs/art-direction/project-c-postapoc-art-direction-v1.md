## 0. 한 줄 방향

> 붕괴 이후 버려진 현대 도시가 녹과 균열과 잡초에 먹히는, **아이소메트릭 픽셀 폐허**.
> 차가운 어둠 위에 국소 인공광(호박색 형광/네온) 웅덩이 + 위험/이상(異常) 신호색 하나.

**공통 문법 (5장 전부에서 반복):**
- **아이소메트릭 픽셀아트**, 두툼하고 깨끗한 픽셀 (기존 PPU 64 감성과 동일).
- **풍화 3종 세트**: ① 녹(주황갈), ② 균열(벽·바닥 양쪽), ③ 자연 잠식(담쟁이/잡초).
- **컷어웨이 디오라마 프레이밍** (특히 04) — 기존 허브 디오라마 방식과 완전히 동일.
- **국소 인공광 웅덩이**: OPEN 사인 글로우, 방폭문 표시등, 주유소 형광등 스트립, 네온.
- **채도 절제**: 바탕은 탈색된 모래/콘크리트/벽돌 → 회갈색 저채도. 고채도는 **광원과 신호에만**.

## 2. 기존 아트 철학과의 관계 — **팔레트 원리는 그대로다**

이게 핵심이다. 기존 "웜 다크 판타지 디오라마"(GDD §6, CLAUDE.md)의 **구조**는
포스트 아포칼립스로 그대로 계승된다. 바뀌는 건 **재료 어휘**뿐.

| 원리(유지) | 판타지 표현(기존) | 포스트아포 표현(신규) |
|------------|-------------------|------------------------|
| 차가운 청흑 void 바탕 | 청흑 void | 청흑 void (동일) |
| 저채도 석조 중간톤 | 자주빛·적갈색 석재 | **콘크리트 회색 · 벽돌 적갈 · 녹 주황** |
| 국소 호박색 광원 | 횃불·모닥불 | **형광등·방폭 표시등·네온·드럼통 불** |
| 국소 고채도 신호색 1개 | 청록 포탈/마법 | **청록 = 이상(異常)/SF 신호** (포탈→균열/이상 현상) |

→ `DisplaySettings`의 조명 오버레이 분리, FOV 3상태(Unknown/Explored/Visible)의
tint+alpha, 상태이상 색(주황 화상/청록 빙결)은 **그대로 유효**하다.
오히려 주황=위험/불, 청록=이상/냉각이라는 현대적 의미가 더 자연스럽게 붙는다.

## 3. 카탈로그 슬롯 매핑 (재작업 = 리스킨, 구조 불변)

`asset-spec-sheet.md`의 51슬롯은 캔버스/피벗/애니 태그를 **그대로 두고 아트만 교체**한다.
로직·정렬·데이터 계약은 건드리지 않는다.

| 슬롯 | 판타지(기존) | 포스트아포(신규 스킨) |
|------|--------------|------------------------|
| `env-floor` | 석재 바닥 | 균열 아스팔트 / 콘크리트 타일 (레퍼 05) |
| `env-wall-*` | 벽돌 석벽 | 콘크리트·벽돌 폐벽 + 균열/담쟁이 (레퍼 03) |
| `env-wall-torch-*` | 벽 횃불 | 벽 **비상등/형광등** (호박색 idle 루프) |
| `env-stairs / stairs-up/down` | 돌계단 | 콘크리트 계단 / 비상계단 (레퍼 02·03) |
| `env-hole` / `env-weak-floor` | 깨진 돌바닥 | **붕괴 철근 바닥 · 꺼진 맨홀** (레퍼 03·05) — 낙하 설득력 ↑ |
| `env-door-*` | 나무/철문 | **방폭문 + 주황 표시등 · 셔터** (레퍼 01) |
| `prop-campfire` (허브 광원) | 모닥불 | **드럼통 모닥불 / 방폭 랜턴** (호박색 루프) |
| `prop-portal` (허브 출정구) | 마법 포탈 | **이상 균열(anomaly rift)** — 청록 신호 루프 |
| `prop-explosive-barrel` | 폭발통 | **연료 드럼 / 프로판** (동일 로직, 더 자연스러움) |
| `prop-stash` (허브 창고) | 보물 궤 | 컨테이너 / 사물함 / 통조림 선반 (레퍼 04) |
| `actor-*` (몬스터) | 고블린·해골·슬라임 | 리스킨 표 별도 — §4 참조 |
