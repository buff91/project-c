## 프롬프트 요약

기존 16:9 스크린샷의 카메라, 아이소메트릭 타일 구조, FOV, 플레이어와 폭발통·드레싱 위치,
HUD 레이아웃과 한글 텍스트를 고정했다. 갈색/토프 면적을 줄이고 냉회색 콘크리트와 청흑 void를
주조색으로 전환하며, 기존 벽 패널에 굵은 시안 서비스광과 마젠타 아케이드광을 각각 부여했다.
광원은 별도 국소 바닥 반사로 제한하고 중앙의 이상현상 틸과 분리했다. 원정자는 얼굴이 노출된
블론드 포니테일 필드 메딕을 유지하되 시안 트리아지 표시와 마젠타 의료 모듈 포인트를 더하도록
지시했다. 새 맵 구조·차량·오브젝트·읽을 수 있는 간판 문구·전역 블룸은 금지했다.
